# 1부 · 용어

## 문제의 기호

```
g = h * f + n
```

| | 뜻 | 아는가 |
|---|---|---|
| **f** | 원본 이미지 (자기 감수율 분포) | **모름 — 찾는 것** |
| **h** | dipole 커널. 한 점이 퍼지는 모양 (PSF) | **앎** — 조교 지침 4 |
| **n** | 노이즈. 4종, σ 가 장마다 다름 | **모름** — 조교 지침 4 |
| **g** | 측정치 | 앎 — 주어진 것 |
| `*` | 합성곱 (convolution) | |

**노이즈가 흐림 뒤에 붙는다.** 이 한 가지가 3일차 설계 전부를 좌우한다 —
측정치 위에서 노이즈가 백색이므로 거기서 지워야 하고, σ 도 거기서 잴 수 있다.

## h 와 D — 같은 커널의 두 얼굴

| | 어디 | 어떻게 작용 |
|---|---|---|
| **h** | 공간 영역 (PSF) | 합성곱 |
| **D** | 주파수 영역 (OTF) | **곱셈** |

`D = FFT(h)`. 합성곱 정리로 `g = h*f` 가 `G = D·F` 가 된다. 코드는 `D` 만 쓴다
(`dipole_otf`) — 곱셈은 나누기로 되돌릴 수 있어서다.

실측: `h` 는 좁다. 반경 4px 안에 에너지의 98%.

## dipole 커널의 식

```
D(k) = 1/3 − (k·B̂₀)² / |k|²
```

**만든 식이 아니라 물리에서 유도된다.** 실공간 쌍극자 장 `(3cos²θ−1)/(4πr³)` 의
푸리에 변환이다 (Salomir 2003, Marques & Bowtell 2005). QSM(정량적 자기 감수율
영상)의 표준 커널이고, 이 과제는 그 2D 축소판이다.

| 각도항 `(k·B̂₀)²/|k|²` | 방향 | D |
|---|---|---|
| 0 | B₀ 와 수직 | **+1/3** ← 최댓값 |
| **1/3** | **54.74° (매직앵글)** | **0** ← 영널 원뿔 |
| 1 | B₀ 와 나란함 | −2/3 ← 최솟값 |

실공간 식 `3cos²θ−1 = 0` 과 주파수 식 `1/3 − cos²θ = 0` 이 **같은 각도**를 준다.
NMR 의 매직앵글 회전과 같은 각이다.

`k=0` 은 방향이 없어 각도항을 0 으로 두는 것이 관례다 → **D(0) = 1/3**.

## DC

**주파수 0, 즉 이미지의 평균 밝기.** 전기의 직류(Direct Current)에서 온 말이다.
균일한 값(예: rician 의 밝기 편향)은 전부 DC 한 자리에 몰린다.

`D(0)=1/3` 이므로 역산은 DC 를 **×3** 한다. 실측 확인: 편향 0.0512 → 0.1537 (×3.00).

## dB · PSNR · SSIM · SNR

**dB (데시벨)** = 비율의 로그. `10·log₁₀(비율)`.
`2¹⁰ = 1024 ≈ 10³` 이라 **+3 dB = 2배**, **+10 dB = 10배**.

| | 재는 것 | 쓰임 |
|---|---|---|
| **SNR** | 신호 에너지 / 노이즈 에너지 | **입력이 얼마나 어려운가** |
| **PSNR** | peak² / MSE | **출력이 얼마나 좋은가** (채점) |
| **SSIM** | 밝기·대비·구조의 일치도 (0~1) | 구조 보존 (채점) |

3일차 입력 SNR 은 **+0.9 dB** — 신호와 노이즈가 거의 같은 크기다.
(1일차는 +8.6 dB. 흐림이 대비를 0.41배로 죽여서 그렇게 된다.)

**주의**: PSNR 의 MSE 는 오차의 **제곱**이라 "+3 dB = 오차 에너지 절반" 이다.
눈에 보이는 오차 크기(RMS)는 1/√2 만 준다.

## 노이즈 4종

| | 성격 | 평균 |
|---|---|---|
| gaussian | 대칭 | −0.0000 |
| **rician** | **복소수의 크기. 음수 쪽이 접혀 올라옴** | **+0.0595** |
| uniform | 대칭 | +0.0001 |
| salt & pepper | 임펄스 (최소/최대값으로 치환) | ≈ 0 |

**rician 만 평균이 0 이 아니다.** MRI 가 복소 신호의 **크기** `√(re²+im²)` 를
쓰기 때문이다. 항상 0 이상이라 음수 쪽 흔들림이 위로 접힌다.

편향은 신호가 약할수록 크다 (σ=0.1 기준): 참값 0 → +0.125, 참값 0.5 → +0.010.
신호가 0 일 때 이론값은 `σ·√(π/2)`.

## Wiener 필터

```
W = D / (D² + λ)
```

**되돌릴 수 있는 것만 되돌리고 나머지는 포기하는 나누기.**

| \|D\| | W | 하는 일 |
|---|---|---|
| 크다 | ≈ 1/D | 제대로 역산 |
| 작다 | ≈ D/λ → 0 | 포기 |

`λ` 가 그 경계를 정한다 (게이트가 `|D| = √λ` 에서 열린다). 그냥 `1/D` 로 나누면
노이즈가 **+51.5 dB (142,438배)** 폭발한다.

우리 파이프라인의 데이터 정합 `x = (D·G + λZ)/(D² + λ)` 는 **`Z=0` 이면 정확히
Wiener** 다. 즉 "Wiener + 네트워크 의견" 이다.

## σ 추정 (널 원뿔)

`|D| < 0.02` 인 주파수에는 dipole 이 신호를 보내지 않는다. 거기 있는 것은 전부
노이즈다. 파세발로 `E|G|² = N·σ²`.

- 정답도 `noise_meta.json` 도 쓰지 않는다. **측정치 하나에서 나온다.**
- 상대오차 **중앙값 1.9%**
- 3일차 σ 는 장마다 **0.0007 ~ 0.1325 (200배)** 차이난다

커널을 알기에 쓸 수 있는 추정기다. MAD 같은 일반 추정기는 이미지의 고주파를
노이즈로 착각한다 (1일차 σ 게이트 실패 원인).

## 전개형 (unrolled network)

```
x₀ = Wiener(g, λ₀)
반복 4회:
    z = DRUNet(x, σ)              사전지식. 학습된다
    x = (D·G + λZ)/(D² + λ)       물리 제약. 닫힌 해, 학습은 λ 뿐
```

최적화 기법 HQS(half-quadratic splitting)를 신경망으로 펼친 것. DPIR(Zhang 2021)
계보다. 데이터 정합은 **학습 파라미터가 없다** — dipole 이 주파수 영역에서 대각
연산자라 닫힌 해로 정확히 풀린다.

관련어: **plug-and-play** 는 사전지식 자리에 이미 학습된 디노이저를 넣고 얼려 두는
것. **전개형** 은 그 디노이저까지 같이 학습하는 것.

## DC-Net · hard/soft data consistency

**hard DC**: `|D|>τ` 인 주파수를 `G/D` 로 못박는다. 2일차(노이즈 없음)에서 42.93.
**soft DC**: 못박지 않고 무게를 둔다 `(D·G+λZ)/(D²+λ)`. 전개형이 이것이다.

`λ→0` 이면 soft 가 hard 가 된다 — **전개형이 DC-Net 의 노이즈 대응 일반형**이다.

## self-ensemble

같은 이미지를 여러 방향으로 뒤집어 넣고 결과를 평균. **dipole 이 견디는 대칭만**
쓸 수 있다 (직접 확인):

| 변환 | 오차 | |
|---|---|---|
| 좌우·상하·180° 뒤집기 | 7e-16 | **쓴다 (4×)** |
| 전치·90° 회전 | **3.17** | **못 쓴다** — B₀ 가 돌아가 연산자가 바뀐다 |

1일차의 8× 를 그대로 가져오면 손해다.

## N2V (Noise2Void) · label-free

정답 없이 노이즈 이미지만으로 디노이저를 학습한다 (Krull 2019).

일부 화소를 이웃 값으로 **가리고**, 가린 자리의 원래 값을 맞히게 한다. 네트워크는
가린 화소를 못 보니 이웃으로 추측해야 하는데 —

| | 이웃으로 예측 가능한가 |
|---|---|
| 신호 | 가능 (공간적으로 이어져 있으니) |
| 노이즈 | **불가능** (화소마다 독립) |

그래서 최적해가 곧 **깨끗한 값**이다. `E[g|이웃] = E[f|이웃] + E[n] = f`.

친척: **Noise2Noise** 는 노이즈 이미지 2장 필요, **N2V** 는 1장이면 된다.

L1 을 쓰는 이유: s&p 와 rician 은 분포가 치우쳐 L2 는 평균으로 끌려간다. L1 은
조건부 중앙값으로 수렴해 그 편향을 피한다.

# 2부 · 예상 질문 20

## 규칙·검증

**Q1. σ 를 모델에 알려준다는데, 노이즈를 알려주는 건 컨닝 아닌가?**

`noise_meta.json` 은 안 씁니다. **측정치 하나에서 계산**합니다. `|D|<0.02` 인
주파수에는 dipole 이 신호를 보낼 수 없으니 거기 있는 것은 전부 노이즈고, 그 파워를
재면 σ 가 나옵니다. 커널을 안다는 건 지침 4가 허용한 것입니다.

그리고 σ 는 **세기 하나(스칼라)** 지 노이즈 자체가 아닙니다. 사진을 보고 "ISO 6400
으로 찍었네" 하는 것과 같습니다 — 입자가 얼마나 거칠지는 알아도 어느 화소가 어떻게
튀었는지는 모릅니다.

추정이라는 증거: 상대오차 중앙값 **1.9%** 입니다. 베꼈으면 0 이어야 합니다.

**Q2. `noise_meta.json` 을 어디에 썼나?**

표를 노이즈 종류별로 쪼개고, 그림의 대표 이미지를 고르는 데만 썼습니다 (배포 안내:
"결과 분석에만"). **복원 함수가 받는 인자는 `measure` 와 `b0` 뿐**이고, 노이즈
종류·σ 를 받는 인자가 아예 없습니다. `check_rules.py` 가 그것을 검증합니다.

**Q3. test 로 하이퍼파라미터를 고르지 않았나?**

처음에는 그러고 있었고, 도중에 발견해 고쳤습니다. K 를 test 에서 스윕하던
`combine_day3.py` 는 폐기하고 나머지를 전부 val 로 옮겼습니다. val 은 val clean 에
forward + 파일명 seed 노이즈를 걸어 만듭니다.

**Q4. metric 은 배포 코드를 썼나?**

그대로 썼습니다. `src/deconv` 에 초기 단계의 skimage 기반 구현이 남아 있어서
이름을 바꿔 가리지 못하게 하고, 다른 구현이 잡히면 즉시 멈추는 가드를 넣었습니다.
작업 중 실제로 한 번 밟았던 함정입니다.

## 문제 이해

**Q5. 1일차와 2일차 답을 이어 붙이면 왜 지나?**

세 가지가 겹칩니다.

1. 2일차 답(`1/D`)은 **노이즈가 0이라 통했습니다.** `n≠0` 이면 노이즈가
   **+51.5 dB (142,438배)** 폭발합니다.
2. 흐림이 대비를 죽입니다. `std(f)=0.222 → std(h*f)=0.092`. 노이즈는 그대로인데
   신호만 줄어 SNR 이 +8.6 → +0.9 dB 가 됩니다.
3. 주파수의 **16%** 는 역산 후 SNR 이 −20 dB 이하로 복원 불가입니다.

가장 잘한 조합(1일차 디노이저 → Wiener)이 21.06 이고, 배포 baseline 25.02 에도
집니다.

**Q6. 디노이징과 디컨볼루션 중 뭐가 먼저여야 하나?**

**디노이징이 먼저입니다.** 노이즈가 흐림 뒤에 붙어 측정치 위에서는 백색이거든요.
Wiener 를 먼저 걸면 노이즈가 `1/D` 로 증폭되고 X자로 상관돼, 디노이저가 본 적 없는
종류가 됩니다.

실측 **4.2 dB 차이**: 디노이징 먼저 21.06, 디컨볼루션 먼저 16.88.

**Q7. 그런데 왜 우리 파이프라인은 Wiener 로 시작하나? (모순 아닌가)**

날카로운 질문입니다. 두 가지로 답할 수 있습니다.

첫째, **한 번만 할 때 생기는 문제**입니다. 전개형은 번갈아 4번 하고 매번 원래
측정치로 되돌아가므로 순서를 고를 필요가 없습니다.

둘째, **디노이저가 이미지 영역에 살기 때문**입니다. `g` 는 측정치이지 이미지가
아니라, 이미지 영역 디노이저에 넣으려면 먼저 이미지로 바꿔야 합니다. 디노이징을
먼저 하려면 디노이저를 측정치 영역에 둬야 하는데(=2단 분해), 그건 15.6 이었습니다.

정직하게 말하면 전개형의 표준 구조(DPIR)를 따른 것이고, 위 이유는 나중에 확인한
것입니다.

**Q8. 왜 이미지 영역이 나은가?**

정답 이미지는 **선명한 주기적 격자**라 사전지식이 매우 강합니다. 흐려진 `h*f` 는
뭉개져 있어 훨씬 덜 예측 가능합니다. 실측으로 전개형(이미지 영역) 29.70 대
2단 분해(측정치 영역) 15.6 입니다.

## 한계와 근거

**Q9. "선형의 천장 21.95" 는 어떻게 계산했나?**

주파수마다 **참 신호 파워와 참 노이즈 파워**를 정답에서 계산해 넣은 위너 필터입니다
(`oracle_linear.py`). 보통 위너는 그 비를 상수 K 하나로 때우는데, 참값을 넣으면
그보다 나을 수 없으니 선형 대각 연산자의 상한입니다. 실제로는 만들 수 없습니다.

**Q10. 정답을 봤는데 왜 완벽하지 않나?**

**파워 스펙트럼만** 봅니다 — 위상은 안 봅니다. 위상이 이미지의 모양을 담고 있어서
크기만으로는 그림을 만들 수 없습니다.

그리고 위너는 **곱하기밖에 못 합니다** (`F̂ = W·G`). 측정치에 없는 것은 어떤 수를
곱해도 안 나옵니다.

오차의 출처: 버린 주파수 32%, 새어든 노이즈 68%.

**Q11. 버린 주파수에 정답이 2.2% 뿐인데 왜 오차의 32% 인가?**

**오차 자체가 정답의 5.17% 밖에 안 되기 때문**입니다. 그 안에서 1.65% 면 3분의 1
입니다. 신호 기준으로는 작지만 오차 기준으로는 큽니다.

PSNR 이 높아질수록 이 효과가 심해집니다 — 남은 오차가 작아지니 같은 손실이
상대적으로 커 보입니다.

**Q12. 그럼 우리 모델은 어떻게 29.70 을 내나?**

**원뿔을 실제로 메우고 있습니다.** 에너지로 따지면:

- 우리 오차 = 정답의 **0.774%**
- 원뿔에 든 정답 = **2.24%**

원뿔을 통째로 포기했다면 오차가 최소 2.24% 여야 하는데 그보다 작습니다. 즉
**원뿔을 포기하는 어떤 방법도 25.08 dB 를 넘을 수 없고**, 우리는 원뿔의 최소 65%
를 메우고 있습니다. (배포 baseline 25.02 가 그 상한에 거의 붙어 있습니다.)

7.75 dB 의 분해: 원뿔을 메워서 최소 3.63 dB, 남긴 주파수를 더 잘 지워서 4.62 dB.

## 설계 선택

**Q13. DC-Net 이 2일차엔 42.93 인데 왜 3일차엔 14.80 인가?**

hard DC 는 `|D|>τ` 를 `G/D` 로 못박는데, `G = D·F + N` 이므로 `G/D = F + N/D`
입니다. **증폭된 노이즈를 못박는 것**이고 네트워크는 그걸 고칠 권한이 없습니다.

τ 를 키우면 못박는 주파수가 줄어 DC 가 무의미해지고, 줄이면 증폭이 폭발합니다
(τ=0.005 에서 200배). **3일차엔 좋은 τ 가 없습니다.**

고칠 방법이 못박지 말고 무게를 두는 것이고, 그게 전개형입니다.

**Q14. 왜 반복을 4번으로 했나? 늘리면 안 되나?**

학습은 4번으로 했고, **추론에서 5·6·8번으로 늘려봤더니 무너졌습니다** (5번에서
20.99). 4단계로 학습한 모델은 5단계에서 분포를 벗어납니다. val 이 알아서 4를
골랐습니다.

**학습부터 6단계로** 하는 것은 아직 안 해봤습니다 (지금 돌리는 중입니다).

**Q15. 왜 self-ensemble 이 4× 인가? 1일차엔 8× 였는데.**

dipole 은 B₀ 방향을 가져서 **90° 회전하면 연산자 자체가 바뀝니다.** 직접 확인했고
(오차 3.17 대 뒤집기의 7e-16), 8× 를 그대로 쓰면 손해입니다. 좌우·상하·180°
세 개와 항등, 총 4개만 유효합니다.

**Q16. σ 조건화가 실제로 얼마나 기여하나?**

가중치는 그대로 두고 σ 입력만 바꿔 쟀습니다 (학습 불필요).

| σ 를 어떻게 | PSNR |
|---|---|
| 추정 σ (장마다) | 29.59 |
| 전체 평균 하나로 | 25.37 (**−4.22**) |
| 전부 0 | 15.93 (−13.66) |
| 2배 / 절반 | 22.5 (−7) |

**장마다 다른 σ 를 주는 것이 하나로 뭉뚱그리는 것보다 4.22 dB 낫습니다.**

**Q17. 왜 rician 만 나쁜가? (22.87 vs 나머지 29~36)**

rician 은 복소수의 크기라 **음수 쪽이 접혀 올라옵니다.** 4종 중 유일하게 평균이
0 이 아닙니다 (+0.0595).

그 편향은 균일하므로 **DC 한 자리에 몰리고**, `D(0)=1/3` 이라 역산에서 **최대 3배**
가 됩니다 (실측 ×3.00). 상수 밝기 오차는 PSNR 을 크게 깎습니다. λ 로 억누르고
있지만 완전히는 못 잡습니다.

**Q19. label-free 가 정말 정답을 안 쓰나? 19.56 은 낮지 않나?**

**손실에 정답이 한 번도 들어가지 않습니다** — `|net(가린 g) − g| · mask` 로,
등장하는 것은 측정치와 마스크뿐입니다. λ 도 측정치에서 정합니다.

다만 학습용 측정치는 train 의 clean 에서 합성했습니다. 3일차 측정치가 따로 주어지지
않았고 test 로 학습하면 규칙 위반이라서입니다.

점수는 supervised 를 이기려는 게 아니라 **"정답 없이 어디까지"** 가 기준입니다.
Wiener 단독 13.79 대비 **+5.77 dB** 입니다.

**Q20. 30 dB 를 왜 못 넘었나? 더 하면 되나?**

30 을 넘기려 세 가지를 시도했고 전부 실패했습니다.

| 시도 | 결과 | 왜 |
|---|---|---|
| 노이즈 통계 조건화 (왜도·첨도) | 29.59 | 첨도가 rician 을 가르지만 모델이 쓰지 않았다 (−0.03 dB) |
| 모델 융합 | 29.66 | 같은 체크포인트의 형제라 틀리는 방식이 같다 |
| 추론 반복 횟수 늘리기 | 20.99 | 분포를 벗어난다 |

**점수를 올린 것은 하나뿐이었습니다 — 수렴할 때까지 더 학습하기** (29.25 → 29.70).
60 에폭으로 끝냈는데 매번 마지막 에폭까지 오르고 있었습니다. 시간이 더 있으면
그것부터 하고, 그다음 rician 편향을 직접 보정하는 항을 넣어 보겠습니다.

**Q21 (보너스). 실제 문제에 쓸 수 있나?**

이 과제는 QSM 의 2D 축소판이고, 커널 식도 실제 물리 그대로입니다. 우리 파이프라인은
학습에 clean 이 필요하지만, **σ 추정은 측정치만으로 되고** label-free 경로도 함께
만들어 뒀습니다. 커널을 아는 다른 역문제(MRI 재구성·CT·현미경)에도 데이터 정합
단계만 바꾸면 그대로 옮길 수 있는 구조입니다.
