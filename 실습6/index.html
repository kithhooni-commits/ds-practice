비전 복싱 (실시간 2인 대전)

MediaPipe Pose Landmarker로 양팔·머리 관절을 추적해 잽·훅·어퍼컷과 더킹·위빙을 규칙 기반으로 판정한다. 상대는 예고 없이 실제로 접속한 사람이고, 서로의 실제 카메라 영상을 보면서 반응해야 한다 — 판정은 각자 자기 화면에서 로컬로 계산하고, 결과만 P2P로 주고받는다.

IN 웹캠 팔·머리 관절 시퀀스 (양쪽) → OUT 기술 판정 + 실시간 P2P 동기화 HP + 승패

범위 메모: 서버 없이 브라우저끼리 직접 연결하는 WebRTC(PeerJS)를 썼다 — 영상 통화용 무료 공개 시그널링 서버를 빌려 쓰는 구조라, 네트워크 환경에 따라(특히 엄격한 NAT/방화벽) 연결이 안 될 수 있다. 얼굴 3D 아바타 학습은 여전히 범위 밖 — 이유는 README 참고.
