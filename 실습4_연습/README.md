## 실습4 본편으로 어떻게 이어지나

**실습4-3이 직접적인 전신이다.** PeerJS mesh 로 브라우저끼리 P2P 대전을 붙였는데,
참가자가 늘수록 연결이 n² 로 늘고 관전자까지 붙으면 감당이 안 된다.
본편에서 **FastAPI + WebSocket 중앙 서버**로 바꾼 이유가 이것이다.

**실습4-4는 구현 전에 따져본 노트다.** 여기 적힌 세 가지 중 **펀치 방향 보정**(자동 조준)과
**단안 3D 얼굴 복원**은 본편에서 실제로 구현했고, **RL 동작 합성**은 하지 않았다.
타당성 판단이 맞았는지 [본편](../실습4/) 결과와 나란히 놓고 볼 수 있다.

## 실행

각 폴더의 `index.html` 을 브라우저로 열면 된다 — 전부 브라우저에서만 도는 데모이고
서버가 필요 없다. 웹캠 권한이 필요하며, `file://` 로 열면 카메라가 막히는 브라우저가 있으므로
그럴 때는 간단한 정적 서버를 쓴다.

```bash
python -m http.server 8080     # 저장소 루트에서
# http://localhost:8080/실습4_연습/
```
